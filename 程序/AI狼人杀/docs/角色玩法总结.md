# 狼人杀角色玩法总结

> 本教程覆盖标准六神民配置：2 狼人、1 预言家、1 女巫、1 猎人、1 守卫、3 村民。
> 每个角色分四个维度展开：角色定位、核心策略、发言技巧、投票建议。

---

## 一、狼人

**角色定位**
狼人是游戏的隐藏阵营，夜间行动与白天伪装是两大核心能力。团队目标是以最小的暴露代价，在白天混淆视听、在夜晚逐轮削减好人数量，最终达成屠边（杀死所有神职或所有村民）的获胜条件。

**核心策略**
- **悍跳 vs 隐狼**：强队常用悍跳（狼队一人跳预言家争夺警徽），弱队可选倒钩（狼藏身好人阵中）。首夜刀通常切随机目标制造混乱，第二夜起优先刀预言家或女巫等关键神职。
- **配合节奏**：狼队夜间必须统一目标，避免各自为战。白天由悍跳狼主导发言，另一只狼装深水民，形成"一狼带头冲锋、一狼装无辜"的经典配合。
- **牺牲换节奏**：警长竞选时若判定警徽必失，可主动倒钩让真预言家拿警徽但反水立警，让好人阵营产生疑点；或冲锋送死换取好人误杀真预言家的局面。
- **阴阳倒钩进阶**：两只狼分别装"冲锋狼"和"倒钩狼"，冲锋狼带头打某一玩家，倒钩狼暗中站边，让好人难以区分真伪。

**发言技巧**
- **悍跳狼**：发言要果断、有信息量，开头直接报查验和警徽流，不要犹豫。参考话术："我是预言家，昨晚验了 X 号是金水（好人），警徽流先验 A 再验 B，过。" 查验结果要具体到"金水"或"查杀"，并说明验人逻辑。
- **倒钩狼**：发言要适度站边真预言家，但要留有空间不被完全识破。参考话式："我这边偏向 X 号是真预，但我还需要听后续发言再确认。"
- **深水狼**：前期多听少说，发言模棱两可但有逻辑，不要过早暴露站边。参考话术："现在信息不足，我先听两边怎么盘，不急着站边。"
- **禁忌**：不要全程划水（一句话不说），容易被盘为狼坑；也不要过于积极打倒钩，反而像身份明着的狼。

**投票建议**
- 悍跳狼要引导队友冲票，白天投票始终与真预言家对立。
- 倒钩狼投票倾向跟随 majority，关键轮次要装得像好人一样纠结。
- 首轮投票可随意，目的是观察阵营分布，第二轮后按战术执行。

## 二、预言家

**角色定位**
预言家是好人阵营最重要的信息位。每晚查验一人身份（狼/好人），查验结果只有本人可见。白天通过跳身份、报查验、留警徽流来传递关键信息，引导好人阵营做出正确判断。

**核心策略**
- **是否上警**：强烈建议上警争警徽。警徽是传递查验信息和组织投票的重要工具。不上警等于放弃指挥权，容易让悍跳狼主导局势。
- **验人优先级**：优先验发言可疑、划水、立场摇摆的玩家。验人顺序建议：首夜验发言最像狼的人，后续按警徽流顺序进行。
- **警徽流规划**：跳预后必须留警徽流（后续验人顺序），让真预死后信息能继续传递。标准格式："我警徽流验 A 号，再验 B 号。" 警徽流要覆盖可能存在的另一只狼。
- **被毒后的选择**：若预言家疑似被毒，可留下遗言说明情况，帮助好人复盘。

**发言技巧**
- **跳身份话术**：简洁有力，直接报查验结果和警徽流。参考话术："我是预言家，昨晚验了 X 号是查杀（或金水），警徽流先验 A 再验 B，X 号是狼，大家跟我投他，过。"
- **面对悍跳时的应对**：不要慌，冷静盘逻辑。重点对比双方发言的信息量和逻辑严密性："他说的验人信息没有细节，我昨晚验的 X 号确实……"
- **被查杀时的反击**：若被悍跳狼查杀，要坚定表态："我是真预，他的查杀是假的。我的查验有警徽流可以验证，请大家看我接下来的验人顺序。"
- **避免过度发言**：预言家发言要精炼，给出查验结果后尽快过，避免说太多导致暴露。

**投票建议**
- 白天投票首要目标是投出被查验的狼人。
- 若无明确查杀，可投发言最可疑的玩家。
- 警长竞选时务必参与投票，支持可信的预言家（自己）。

## 三、女巫

**角色定位**
女巫拥有解药和毒药各一瓶，是好人阵营最强的控场角色。解药可以救活当夜被狼杀的玩家，毒药可以杀死一名玩家。两张药各只能用一次，是游戏中最具策略深度的角色之一。

**核心策略**
- **首夜救人不救**：主流观点倾向于首夜救人。理由：首夜被刀的大概率是平民或神职，救回一人等于多一个信息源；且女巫首夜不用药会产生"女巫首夜没用药"的隐含信息，反而暴露身份。
- **解药使用原则**：第一瓶解药尽量用在首夜或明确被狼刀的好人身上。后续救人要谨慎，避免被狼识破女巫身份后连续刀你守护的目标制造"平安夜假象"。
- **毒药使用时机**：
  - 首夜毒药通常不急于用，除非你对某人已有强烈怀疑。
  - 第二天白天若有人被指出为狼，可用毒确认；或在夜晚用毒"表水"（证明自己是女巫）。
  - 毒药要慎用于关键神职（如预言家）身上，避免误杀。
- **身份曝光策略**：女巫可以选择 early 跳身份或 late 跳身份。early 跳可快速用毒找狼，late 跳可隐藏身份在关键时刻发挥作用。

**发言技巧**
- **未跳身份时**：发言要像普通村民，不过分积极也不过度划水。参考话术："我暂时看不出谁有问题，先听大家发言，我是普通村民。"
- **跳身份时**：明确告知手中有几瓶药，以及用药记录。参考话术："我是女巫，昨晚救了 X 号（或没救人），还有一瓶毒，今晚准备用。"
- **被质疑时的应对**：若被怀疑是狼，可以用用药记录自证："我首夜用了药救了某人，这是可以验证的信息。"

**投票建议**
- 未跳身份时投票要谨慎，跟随 majority 即可。
- 跳身份后可直接投怀疑对象，用投票来强化自己的判断。
- 若毒药已用，投票可以更激进；毒药未用时保持低调。

## 四、猎人

**角色定位**
猎人是好人阵营的威慑力量。被放逐或被狼杀时可开枪带走一名玩家；但若被毒死则不能开枪。猎人的存在让狼人不敢轻易刀神职，也让好人有了翻盘的手段。

**核心策略**
- **开枪时机**：
  - 被放逐时：若确定某人是狼，果断开枪带走；若有疑虑，可装死保留子弹等待后续机会。
  - 被狼刀时：同样果断开枪，不留遗憾。
  - 被毒时：不能开枪，因此要尽量避免被毒。
- **身份曝光**：猎人通常选择 late 跳身份，在关键时刻开枪翻盘。early 跳容易被女巫毒杀或狼人针对。
- **枪法选择**：优先枪杀明确为狼的玩家，其次是发言最可疑的；若无法确定，可选择不开枪（装死）。
- **与女巫的配合**：猎人要警惕女巫可能误毒自己，发言时避免暴露猎人身份，给女巫判断空间。

**发言技巧**
- **未跳身份时**：像普通村民一样发言，但要有一定逻辑分析能力。参考话术："我认为 X 号发言有问题，但他可能是挡刀的，我还需要更多信息。"
- **跳身份时**：简要说明身份，不必透露开枪计划。参考话术："我是猎人，现在不确定谁是狼，我会先观察。"
- **被投票时的遗言**：这是猎人最关键的发言时机。要留下明确的指向："我是猎人，我确定 X 号是狼，我带走他。" 或 "X 号发言太像狼了，我怀疑是他。"

**投票建议**
- 白天投票优先投怀疑对象，但也要避免被狼人带节奏。
- 若确定某人是狼且自己不会出局，可直接站边真预言家。
- 被投票出局前，可以投票给可疑对象以留下指向。

## 五、村民

**角色定位**
村民是好人阵营的基础力量，无特殊技能，完全依靠推理和投票找出狼人。村民数量多（通常 3 个），投票权大，是好人阵营获胜的关键。

**核心策略**
- **信息收集**：认真听每个人发言，记录逻辑漏洞和可疑点。重点关注：发言矛盾、过度划水、立场反复无常、查验信息不合理。
- **逻辑推理**：将发言线索串联起来，找出狼人可能的行为模式。例如：谁在盲目跟票？谁在攻击明确的好人？谁的发言没有实质信息？
- **身份猜测**：不要过早暴露自己知道的信息，避免被狼人针对。可以在适当时候试探性发言："我感觉 X 号发言有问题，但不确定。"
- **配合神职**：信任预言家的查验结果，支持女巫和猎人的合理决策。

**发言技巧**
- **基础发言格式**：报明自己的身份和判断，给出理由。参考话术："我是村民，目前我觉得 X 号和 Y 号发言有问题，因为他们的逻辑站不住脚。"
- **表达犹豫**：村民发言可以体现思考过程，不要装得太像神职。参考话术："我暂时站边预言家，但我还需要听更多发言再确认。"
- **反驳技巧**：当发现别人发言有矛盾时，直接指出。参考话术："刚才 X 号说他是好人，但 Y 号说他昨晚的行为像狼，这两点我需要理清。"
- **避免的发言**：
  - 不要全程不说话（容易被投出局）。
  - 不要过度激进打倒钩（像狼）。
  - 不要盲目跟风投票（容易被狼利用）。

**投票建议**
- 投票是村民最重要的武器。每轮投票都要认真考虑。
- 优先投票给发言最可疑、逻辑最站不住脚的玩家。
- 当真预言家存在时，坚定支持真预言家阵营的投票。
- 若信息不足，可暂投随机或跟随多数，但要记录每个人的投票倾向。

## 六、守卫

**角色定位**
守卫每晚可以守护一名玩家，被守护者当晚不会被狼人杀死。若守护与狼刀目标相同，则为平安夜（无人死亡）。守卫是好人阵营的重要防御角色，能保护关键神职不被狼刀，同时制造平安夜来迷惑狼人。

**核心策略**
- **守护优先级**：
  - 首夜：建议守护自己（自守）或随机守护，观察后续情况。
  - 后续夜晚：优先守护预言家（保护核心信息位），其次守护女巫（防止被毒误杀后无药可用）。
- **空守策略**：有时故意空守一晚，让狼人以为无人被守护而放松警惕，为后续防守创造优势。
- **连守问题**：不要连续守护同一玩家，避免被狼人识破规律。通常建议隔天守护或轮换守护不同玩家。
- **与女巫配合**：守卫和女巫的守护/救人目标相同时会形成平安夜，这是一种有效的战术——既保护了关键角色，又让狼人无法判断实际目标。

**发言技巧**
- **未跳身份时**：像普通村民一样发言，不过分强调自己的角色。参考话术："我目前看不出来谁是狼，大家的发言我都记下了。"
- **跳身份时**：简要说明自己的守护记录（不透露具体守护了谁，避免被狼针对）。参考话术："我是守卫，昨晚守护了某人，具体情况不方便透露，但我相信好人阵营。"
- **被质疑时**：可以用投票记录或部分发言逻辑来证明自己不是狼。

**投票建议**
- 白天投票遵循好人阵营的共识，优先投票给可疑对象。
- 若自己跳了守卫身份，投票可以更激进，展现好人立场。
- 若未跳身份，投票要谨慎，避免被狼人认为你是神职。

## 附录：通用发言模板

### 首夜发言（第一天）
- 预言家："我是预言家，昨晚验了 X 号是金水/查杀，警徽流先验 A 再验 B。"
- 女巫："我是女巫，昨晚用了药/没用药，现在还有 X 瓶药。"
- 猎人："我是猎人，目前不确定谁是狼，我会先观察。"
- 守卫："我是守卫，昨晚守护了某人。"
- 村民："我是村民，现在信息不足，我先听大家发言。"

### 被投票出局遗言
- 好人："我是 XXX，我认为 X 号是狼，大家跟他走。"
- 狼人："我是好人，X 号在倒钩我，大家不要信他。"

### 悍跳狼话术
- "我是预言家，昨晚验了 X 号是查杀，警徽流先验 A 再验 B。"（注意：要像真预一样有细节和逻辑）

## 注意事项

1. **信息隔离**：每个角色的发言要符合其已知信息，不要泄露不该知道的内容。
2. **节奏控制**：游戏节奏由好人的信息传递效率决定，狼人则试图制造混乱。
3. **灵活应变**：以上策略为通用指导，实际游戏中需根据具体局势调整。
4. **团队合作**：狼人需要默契配合，好人需要信息共享，良好的沟通是获胜的关键。
