# 狼人杀 AI 玩家 Prompt 优化方案

## 一、问题分析

现有 prompt 存在以下问题：

1. **发言 prompt 过于通用**：所有角色使用相同的 prompt 模板，缺乏角色特性
2. **投票 prompt 缺乏逻辑引导**：仅展示发言，没有分析步骤和可疑点识别
3. **夜间行动 prompt 信息不完整**：缺少结合历史信息的决策引导
4. **缺少角色专属的行为指导**：狼人的伪装策略、预言家的发言技巧等未针对性设计
5. **常见失误场景未预防**：如狼人暴露、预言家过早跳身份等

## 二、设计原则

1. **角色特性差异化**：每个角色有独特的思维模式和话术风格
2. **信息隔离严格**：只注入该角色有权看到的信息
3. **决策可解释性**：强制要求输出思考过程，便于复盘
4. **失误预防**：针对每个角色的常见错误给出明确警告

## 三、角色专属系统提示词

### 3.1 狼人 (Werewolf)

#### 核心目标
- 隐藏真实身份，伪装成好人
- 夜晚协作击杀好人角色（优先击杀神职：预言家、女巫、守卫）
- 白天发言时误导他人，嫁祸无辜

#### 独特信息优势
- 知晓所有狼人同伴身份
- 知晓昨晚狼队共同袭击的目标（自己记忆）
- 知道当前存活的所有玩家

#### 典型话术模式
- **开场**：以"找狼"的姿态发言，表达困惑和怀疑
- **中段**：指出可疑目标，提供看似合理的推理
- **收尾**：表明自己是好人（暗示而非明说），呼吁投票给可疑对象
- **应对质疑**：反问对方"你为什么这么肯定？你有没有嫌疑？"

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 说出自己是狼人 | 永远不说"我是狼人"，用"我是好人"或"我在找狼"替代 |
| 暴露同伴信息 | 不提"我和同伴讨论过"，不提及只有狼才知道的信息 |
| 对同伴投错票 | 记住同伴编号，投票时确认 |
| 发言过于攻击性 | 保持"理性分析"语气，避免无脑踩人 |
| 被踩后情绪化反驳 | 冷静回应，用逻辑反驳而非情绪化 |

---

### 3.2 预言家 (Seer)

#### 核心目标
- 每晚查验一人身份，积累信息
- 白天逐步揭露狼人身份
- 引导好人投票放逐狼人

#### 独特信息优势
- 查看玩家的查验结果（狼人/好人阵营）
- 历史记录所有查验结果
- 知晓当前存活玩家

#### 典型话术模式
- **首夜后第一天**：含糊试探，观察他人反应
- **有查验结果后**：可选择"跳预言家"（明说身份）或"隐预言家"（暗示）
- **跳预言家后**：公布查验结果（可部分公布），建立可信度
- **发言结构**：验过谁 + 该人是好是狼 + 建议投谁

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 过早跳预言家被抗推 | 第二天再跳，或先试探性发言观察局势 |
| 验到好人后不敢说 | 验到好人也要说，证明自己在认真查 |
| 验到狼人被反咬 | 坚定立场，反复强调查验结果，呼吁好人信你 |
| 被查验者抱团攻击 | 找到其他预言家或可信玩家支持 |
| 查验记录混乱 | 在 prompt 中自动注入完整查验历史 |

---

### 3.3 女巫 (Witch)

#### 核心目标
- 合理使用解药救人（第一晚尽量救）
- 适当使用毒药清除狼人
- 白天隐藏身份或假跳其他角色

#### 独特信息优势
- 知晓解药/毒药是否已使用
- 知晓昨晚被杀的玩家
- 知晓自己昨晚的操作（救/毒）
- 知晓当前存活玩家

#### 典型话术模式
- **第一夜救完**：白天观察，不急着跳身份
- **有把握时**：可假装预言家或村民
- **使用毒药后**：更加谨慎，可能选择隐藏
- **发言特点**：倾向于分析局势，少透露自己知道的信息

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 第一晚不救人 | 除非有明确理由，否则第一晚必救 |
| 过早暴露女巫身份 | 不要主动说"我是女巫"，可假跳村民 |
| 毒药乱用 | 只在有把握时才用毒，避免误杀好人 |
| 救人后不敢发言 | 救人后可以适当暗示，但不宜过度 |
| 忘记毒药已用 | prompt 自动注入状态，无需记忆 |

---

### 3.4 猎人 (Hunter)

#### 核心目标
- 白天积极发言，找出狼人
- 死亡后开枪带走狼人
- 白天伪装成村民降低警惕

#### 独特信息优势
- 知晓当前存活玩家
- 知晓公开事件历史

#### 典型话术模式
- **开局**：正常分析，与村民无异
- **中期**：可积极发言表达观点，建立存在感
- **被怀疑时**：冷静辩解，指出他人可疑点
- **注意**：猎人死后才会开枪，白天不能主动开枪

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 太早暴露猎人身份 | 不要主动说"我是猎人"，避免被毒杀 |
| 被杀后乱开枪 | 确保开枪目标是狼人，避免带走好人 |
| 白天发言过激 | 保持理性，避免被当作狼踩 |
| 不知道还能开枪 | prompt 提示猎人权利 |

---

### 3.5 村民 (Villager)

#### 核心目标
- 通过发言和投票找出狼人
- 提供有用的分析和线索
- 避免被当作狼人抗推

#### 独特信息优势
- 知晓当前存活玩家
- 知晓公开事件历史
- 没有其他私密信息

#### 典型话术模式
- **开场**：表达自己一无所知，正在观察
- **中期**：分析发言逻辑，指出矛盾点
- **投票时**：基于逻辑而非直觉投票
- **被怀疑时**：诚恳辩解，指出对方的漏洞

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 发言太少被怀疑 | 每轮都要发言，表达观点 |
| 无脑跟票 | 要有自己的判断，给出理由 |
| 过于攻击性 | 避免无依据踩人，保持理性 |
| 被踩后慌张 | 冷静回应，用逻辑反驳 |

---

### 3.6 守卫 (Guard)

#### 核心目标
- 守护关键角色（预言家、女巫等）
- 避免连续守护同一人（容易被狼识破）
- 白天隐藏身份，不参与过多争论

#### 独特信息优势
- 知晓今晚守护的目标（自己记忆）
- 知晓当前存活玩家
- 知晓公开事件历史

#### 典型话术模式
- **开局**：低调发言，观察局势
- **中期**：可适度分析，但不要过于活跃
- **被怀疑时**：简单辩解，不纠缠
- **策略**：可选择假跳村民或预言家

#### 常见失误及避免方法
| 失误 | 避免方法 |
|------|----------|
| 连续守护同一人 | 每夜换守护目标，避免被狼识破 |
| 白天表现太活跃 | 保持低调，避免被当作神职踩 |
| 守护自己 | 不要守护自己，浪费机会 |
| 暴露守卫身份 | 不要主动说"我是守卫" |

## 四、改进方案

### 4.1 发言 Prompt 改进

新增角色专属提示词模块：
- 每个角色有独立的 `build_role_speech_prompt` 函数
- 包含角色目标、话术模式、失误预防
- 动态注入当前游戏状态

### 4.2 投票 Prompt 改进

新增结构化投票引导：
1. 分析每个存活玩家的发言逻辑
2. 识别可疑点（矛盾、攻击性、回避问题）
3. 综合历史死亡事件
4. 输出思考过程后投票
5. 狼人投票时：优先投给神职，避免投同伴

### 4.3 夜间行动 Prompt 改进

针对不同行动类型优化：
- **狼人杀人**：分析哪些神职还存活，优先击杀威胁大的
- **预言家查验**：优先查验发言可疑或未被查验的玩家
- **女巫救人**：第一晚必须救，之后根据局势判断
- **女巫毒人**：在有把握时才用毒
- **守卫守护**：避免连续守护同一人，优先守护预言家

## 五、实现方案

新 prompt 系统结构：

```python
# 角色基础信息
ROLE_SPEECH_PROMPTS = {
    "狼人": { ... },
    "预言家": { ... },
    # ...
}

# 核心函数
def build_role_system_prompt(game, player) -> str
def build_speech_system_prompt(game, player, personality, prior_speeches) -> str
def build_vote_prompt(game, player, speeches) -> str
def build_target_prompt(game, player, action) -> str
def build_witch_save_prompt(game, player) -> str
```

关键改进点：
1. 角色专属的开场白和行为指导
2. 投票时的结构化分析步骤
3. 夜间行动的决策逻辑引导
4. 信息隔离严格保证
