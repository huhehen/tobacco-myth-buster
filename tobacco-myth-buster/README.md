# 驳斥"烟草纳税供养航母"说法：数据调研报告

## 核心结论

**烟草行业对国家财政的贡献远小于其造成的健康和经济代价。**

- 2025年烟草行业财政总额：**15,800亿元**
- 2025年国防预算：**18,100亿元**
- 2020年吸烟经济总成本：**24,300亿元**（医疗+生产力损失）
- **净经济损失：约 9,000亿元/年**

## 关键发现

### 1. 税收 vs 国防
- 烟草财政占国防预算比例：约 **87%**（2025年）
- 但烟草财政≠全部用于国防，国防预算有独立来源

### 2. 经济成本 vs 财政收益
- 每收进 **1元** 烟草税，社会付出约 **1.6元** 的健康成本
- 净损失约 **9,000亿元/年**

### 3. 烟民规模
- 中国烟民数量：约 **3亿人**
- 15岁及以上人群吸烟率：**23.2%**（2024年）
- 二手烟暴露影响：**7亿非吸烟者**

## 思想原因分析

烟民提出"烟草纳税供养航母"的说法，主要源于：

1. **认知偏差**：高估个人贡献，低估社会成本
2. **心理防御机制**：为自身成瘾行为寻找合理化借口
3. **信息不对称**：不了解烟草真实的经济成本
4. **群体认同**：将个人消费行为与国家利益绑定

---

## 建议行动

1. **提高烟草税**，降低吸烟率
2. **加强公众教育**，普及烟草真实经济成本
3. **扩大无烟环境立法覆盖**
4. **推广戒烟服务**
