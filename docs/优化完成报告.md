### ✅ 3. 提示词优化已实施

#### 修改文件
- [backend/ai/prompts.py](../backend/ai/prompts.py) - 核心提示词优化
- [backend/ai/speaker.py](../backend/ai/speaker.py) - 投票位置感知

#### 具体改动

**1. 角色提示词增强（6 个角色全部更新）**
- 每个角色新增「绝对禁止的行为」列表（⛔ 标记）
- 每个角色新增「应该避免的行为」列表（⚠️ 标记）
- 补充具体的话术示例和应对策略

**2. 投票 Prompt 优化**
- 新增 `vote_position` 参数（如"第 3/7 个投票"）
- 根据投票位置提供策略建议（早投更自由，晚投信息更多）
- 强制 JSON 输出格式，便于解析
- 新增「好人投票策略」和「反模式预防」章节
- 明确列出常见的投票错误和正确做法

**3. 发言 Prompt 优化**
- 新增「发言技巧」章节（开场、中段、收尾结构）
- 新增「禁止行为」列表
- 强调"如果被点名要直接回应"

**4. 新增每日总结机制**
- 新增 `build_daily_summary_prompt()` 函数
- 让 AI 主动总结当天事件、信任评估、怀疑目标、明日策略
- 帮助维护跨天记忆，避免信息丢失

**5. 投票位置感知**
- `speaker.py` 中计算每个玩家的投票顺序
- 传递给 `build_vote_prompt()` 用于策略调整

## 进一步优化建议（未实施）

以下建议可作为后续优化方向：

1. **JSON Schema 验证**：使用 Pydantic 验证 LLM 输出，失败自动重试
2. **提示词外部化**：将 YAML 提示词文件分离，便于非开发人员维护
3. **缓存分层**：使用 CACHE_TIER_MARKER 分隔共享规则和个性化内容
4. **双层扮演**：引入 Layer 1（性格）+ Layer 2（角色）机制
